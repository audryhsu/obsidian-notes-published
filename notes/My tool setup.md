# My tools
...On MacOs
## Terminal
- [Chezmoi](https://www.chezmoi.io/) for [Managing Dotfiles](./Managing%20Dotfiles.md) 
- [Bash](../Bash.md) shell - zsh and ohmyzsh
- Vim with a [great cheatsheet](https://vimsheet.com/)
- tldr
- navi - searchable and customizable terminal command snippets library. Can import `tldr` snippets.
- github CLI - also used by Claude Code access
- [btop](https://github.com/aristocratos/btop) to monitor resource usage and stats for processor, memory, disk, and network
## Productivity
- [Obsidian](https://obsidian.md/) - notetaking
	- Obsidian Git plugin - versioning my notes to a private repository 
	- Github publisher plugin - publish my notes and drawings to [my public notes repository](https://github.com/audryhsu/obsidian-notes-published)
	- Daily note
		- Rollover Daily Todos plugin - emulates bullet journal method of rolling over incomplete or in progress tasks
- [Excalidraw](https://excalidraw.com/) - drawings, integrated into Obsidian
- [Arc](https://arc.net/) Browser
- [Raycast](https://www.raycast.com/) - command palette for MacOS
- [Amethyst](https://ianyh.com/amethyst/) - window manager
- Karabiner Elements - rewire my keyboard
